## 从一个工作区助手开始

给程序一个任务：“读取 README，告诉我这个项目如何运行。”程序需要让模型看到请求，接收模型提出的文件读取动作，执行工具，再把结果交回模型。这个往返过程是全书的起点。

接下来，助手会面对更长的任务：记录计划、寻找相关知识、管理上下文，在得到批准后修改练习文件；最后把工作拆给独立执行者，并在退出后继续。每章围绕其中一个问题，增加一个可以观察与验证的机制。

主线使用 `langchain-rust + graph-flow`。先写出显式循环，看清消息和工具如何往返，再将循环映射为图节点。模型提出行动请求，应用检查权限、预算和执行结果，运行时记录推进位置。

## 学完能解释什么

- 沿一次模型与工具交互，说明消息、调用 ID、执行结果和停止条件。
- 区分模型接口、图调度、应用策略与存储各自的职责。
- 说明待办、图节点、持久化任务、长期记忆和子 Agent 的联系。
- 用正常与失败实验判断一项能力验证到了哪一步。

本课程建设的是支撑模型行动的 Harness：工具、知识入口、状态、策略和资源管理。前置知识为 Rust 的结构体、枚举、trait、`Result`、所有权、JSON 和基本 `async/await`；Tokio 与框架接口随章节逐步介绍。

| 阅读目标 | 路线 |
| --- | --- |
| 准备动手环境 | 先完成[环境准备](./setup.md)，运行 Rust 基础自检；模型与数据库随实验阶段配置。 |

| 理解最小循环 | 先读 R00 建立全貌，沿 R01 理解显式循环，再运行 R02 的独立工程，观察工具注册和图映射。 |
| 构建长期任务助手 | 在基础循环上学习 R03–R18 的策略、上下文、存储、调度与团队。 |
| 检验真实运行边界 | 在对应主线机制通过后完成 P01–P05 的恢复、幂等与评估专题。 |

每章会说明所用的基础内核和新增机制。章节相邻表示阅读顺序，具体依赖以[学习路径](./learning-path.md)的“前置与基础”为准。
