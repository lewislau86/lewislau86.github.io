## 同一个助手，逐步扩大责任

从“读 README，解释如何运行”开始，再扩展为“根据当前资料制作升级报告，保留来源，发布前等待批准”。先完成[环境准备](./setup.md)，随后按十个阶段推进：

| 阶段 | 助手遇到的新问题 | 学完要拿出的证据 |
| --- | --- | --- |
| 基础循环与执行边界 · 第 0–4 章 | 模型怎样提出动作，谁决定执行？ | 工具消息配对、权限、停止与生命周期轨迹。 |
| 图编排与会话 · 第 5–7 章 | 状态怎样选择后继、等待输入和并行归并？ | 真实路由、跨进程 SessionStorage、失败与共享状态实验。 |
| 计划与隔离 · 第 8–9 章 | 多步任务怎样保持意图，委派怎样隔离历史？ | 合法计划迁移、父子消息和预算边界。 |
| 方法、知识与记忆 · 第 10–15 章 | 每轮该带入什么方法、资料和历史？ | 技能按需加载、当前证据、上下文预算和来源清楚的输入。 |
| 常见设计模式 · 第 16–23 章 | 怎样选择提示链、路由、并行、重规划与控制权交接？ | 真实 graph-flow 模式合同、故障与组合验证；模型对照入口已提供，真实服务另验。 |
| 恢复、长任务与调度 · 第 24–27 章 | 出错、退出或等待以后怎样继续？ | 有限重试、持久状态、任务句柄和触发身份。 |
| 团队与资源 · 第 28–31 章 | 多个执行者怎样协作而不争抢？ | 协议、所有权、租约和工作区归属。 |
| 外部能力与集成 · 第 32–33 章 | 外部工具怎样进入同一条任务链？ | 连接生命周期，以及选定契约的端到端效果。 |
| 可靠性与目标 · P01–P05 | 能运行以后，怎样判断可恢复、有效且完成？ | 检查点、幂等、质量、演练和独立目标判断。 |
| 受控演进 · P06 | 改进是否可信，失败怎样回滚？ | 固定评估边界、有限候选和发布记录。 |

这些阶段先解决动作和输入，再学习如何选择控制结构，随后扩大时间、进程与协作边界，最后检查效果与改进。MCP 的概念在导读中先认识，实现在 R19 学习，因为它涉及前面已讲过的权限、错误和资源生命周期。

## 阅读顺序与实现依赖

主线使用连续章号：图编排是第 5–7 章，RAG 是第 11 章、联网搜索是第 12 章，放在技能之后、上下文压缩之前。实验标识 Rxx、Gxx、Kxx、Dxx 与 Pxx 用于原命令、轨迹和校验记录，不等同于章号；主题网址保持稳定。相邻章节构成叙事顺序，各节点的“前置与基础”才是必要依赖；独立实验可以按前置跳读。

第 16–23 章使用 D01–D08 作为稳定实验标识，运行 `python3 run.py run D01` 等命令。先读[本部分导读](./agent-design-patterns.md)，再按连续导航运行各章；第 23 章附标准 OpenAI 兼容服务对照入口。默认验证不调用真实模型。

图编排沿[导读](./graph-orchestration.md) → [状态路由](./graph-state-routing.md) → [暂停恢复](./graph-pause-resume.md) → [并行子图](./graph-parallel-subgraphs.md)阅读。如果只想先理解知识接入，完成 R02、R03 后，可读 R07 → K01 → R08 → R09 → R10，再回到长任务路线。研究资料见[研究补充](./research-updates.md)，实现前先确定基线与验收口径。
