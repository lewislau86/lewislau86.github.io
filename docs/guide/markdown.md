# Markdown 写作示例

这篇文档展示知识库常用的排版方式。编辑时可以参考本页的 Markdown 源文件。

## 标题与正文

使用 `#` 表示文章标题，`##` 和 `###` 表示章节。每篇文档建议只有一个一级标题。

正文支持 **重点强调**、*斜体* 和 `行内代码`。段落之间留一个空行，便于阅读和维护。

## 链接与列表

通过相对路径引用其他文档，例如 [新增与发布文档](./writing.md)。

- 用无序列表整理并列信息。
- 用有序列表描述操作步骤。
- 一个列表项尽量只表达一个要点。

## 代码块

在代码块开头注明语言，可以获得语法高亮：

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("Lewis"))
```

## 表格

| 内容 | 建议写法 |
| --- | --- |
| 背景 | 说明问题和约束 |
| 方案 | 说明做法和取舍 |
| 验证 | 记录结果与适用范围 |

## 提示块

::: tip 写作建议
先说明要解决的问题，再介绍方案与示例，便于读者理解。
:::

::: info 验证范围
记录实验结果时，同时写明环境、条件和仍未验证的部分。
:::

## 图片

把图片保存在文档附近，例如 `docs/guide/images/example.png`，然后使用相对路径引用：

```md
![图片的简要说明](./images/example.png)
```
