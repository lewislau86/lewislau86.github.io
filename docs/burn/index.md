## 贯穿全书的小模型

下面这组数贯穿张量、模型、后端与梯度章节。后续代码都先核对同一个计算目标：

```text
输入 X = [[1, 2]]
权重 W = [[1, -1], [2, 1]]
偏置 b = [0, 1]

XW = [[5, 1]]
Z = XW + b = [[5, 2]]
H = ReLU(Z) = [[5, 2]]
```

`ReLU` 对每个数取 `max(0, x)`。这是固定参数的一次前向，输出还没有被赋予分类概率等业务含义。GPU 章节另用向量加法和小矩阵讲解工作划分，训练章节用 `y=2x+1` 检查模型拟合与文件往返。

## 怎样安排第一遍阅读

| 阅读目标 | 建议路线 |
| --- | --- |
| 系统理解框架 | 按第 1～18 章推进，首次遇到设备专用优化时先记录问题。 |
| 先跑出一个结果 | 准备第 1 章环境，核对第 2～4 章基础，运行第 7 章，再回到完整路线。 |
| 研究内核与性能 | 重点完成第 5～6、9、12～15 章，并用第 17 章定位实现。 |
| 借助 PyTorch 学习 | 学到前向、模型、求导与更新时，分别查第 16 章对应内容。 |

没有 NVIDIA GPU 也可以学习：第 5～6 章先完成手算和源码阅读，其余章节按 Flex CPU 学习包推进。CUDA、Rust CUDA 与后续 WGPU/Metal 实验分别记录自己的环境，不能把 CPU 数值检查当成 GPU 验证。
