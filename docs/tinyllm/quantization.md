# 第 28 章：量化

[课程总览](./index.md) · [上一章](./attention-kernels.md) · [下一章](./speculative-decoding.md)

::: info 本章状态：规划中
正文与 notebook 尚未完成。前三章都在减少工作量或提高单位工作的效率，本章直接减小要搬的数据本身。预计覆盖：

- **先把公式写出来。** 对称量化只有缩放因子 $s$，非对称再加零点 $z$；反量化是 $x \approx s(\hat{x} - z)$。用第 12 章嵌入表里的一行真实权重算一遍误差。
- **按什么单位量化。** 整个张量共用一个 $s$，还是每行一个（按通道），还是每 $g$ 个数一个（分组）；分组越小误差越低，但要多存更多缩放因子。
- **权重压到 INT8 与 INT4。** 在训练好的 TinyLLM 上，分别量化嵌入表、注意力和前馈层的权重，比较验证集困惑度与生成样例；同时算出权重占用从多少字节变成多少字节。
- **激活的离群值。** 权重好压缩，激活里少数特别大的值会撑坏整个量化范围；SmoothQuant 用一次等价变换把难度从激活搬到权重，只讲思路和它为什么等价。
- **KV cache 量化。** 缓存同样可以按 token 分组量化，代价是注意力分数更粗糙；和[第 26 章](./inference-efficiency.md)的缓存字节数一起算。
:::

## 本章主线选择（待实验验证）

量化对象先只有<strong>权重</strong>，顺序是：按通道 INT8 → 分组 INT8 → 分组 INT4，每一步都在同一验证集上比较困惑度和生成样例，并记录权重占用的字节数。训练和评估的精度设置沿用[第 19 章](./precision.md)；量化和混合精度是两件事——混合精度管“用什么格式计算”，量化管“用什么格式存储和搬运”。

判断能不能接受要写清口径：困惑度涨了多少、生成样例与基线差在哪里、在多少个种子上测。INT4 的误差在小模型上通常比大模型更明显，本章的实验只能说明这个尺寸下的情况，不能外推到更大的模型。计算加速不在本章结论里：CPU 上没有 INT4 的张量核心，本章测的是<strong>体积与质量</strong>，速度留给标注了 GPU 的实验。
