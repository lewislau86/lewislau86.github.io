# 第 35 章：退火与数据配比

[课程总览](./index.md) · [上一章](./inference-optimization.md) · [下一章](./long-context.md)

::: info 本章状态：规划中
正文与 notebook 尚未完成。从这一章开始是第七部分“中训练”：预训练产出的基础模型，往往还要再训一段才交给后训练。数据量比预训练少得多、比后训练多得多，训练目标仍然是下一个 token 的交叉熵。预计覆盖：

- **中训练是什么。** 它和预训练、后训练的分界；为什么很多技术报告把它写进“预训练”的后几个阶段（例如 Qwen3 的第 2、3 阶段）。
- **退火段换数据。** [第 17 章](./learning-rate.md)的 WSD 衰减段是损失“下台阶”的地方，这一段上采样高质量数据（数学、代码、推理、精选文本）。
- **从任意检查点分叉。** WSD 的稳定段可以随时停下来接一段衰减，于是能低成本比较不同的退火数据。
- **配比与长度。** 退火数据占多少、退火段多长；高质量数据太少时会被背下来。
:::
