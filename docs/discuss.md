# 读者讨论

欢迎交流 TinyLLM、mini-redis 和 Burn 教程中的问题，也欢迎补充资料和指出错误。可以在本页下方留言。

- 想讨论某篇文章，请到文章底部的“读者讨论”留言，回复会集中在该文章对应的话题中。
- 想提出跨章节的问题或新主题，请前往 [GitHub 讨论区](https://github.com/lewislau86/lewislau86.github.io/discussions)。

留言使用 GitHub 账号。讨论内容公开显示在本站和仓库的 GitHub Discussions 中。
